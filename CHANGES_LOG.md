## 🔍 SCHEMA IMPROVEMENTS

### Before
```json
{
  "openingHoursSpecification": {
    "dayOfWeek": ["Monday", "Friday"],
    "opens": "08:00",
    "closes": "17:00"  // Missing Saturday
  }
}
```

### After
```json
{
  "openingHoursSpecification": [
    {
      "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"],
      "opens": "08:00",
      "closes": "18:00"  // Extended hours
    },
    {
      "dayOfWeek": ["Saturday"],
      "opens": "09:00",
      "closes": "16:00"  // Saturday added
    }
  ]
}
```

✅ **Improvements:**
- Extended weekday hours (17:00 → 18:00)
- Added Saturday hours
- Proper array format for multiple specs
- More complete information
